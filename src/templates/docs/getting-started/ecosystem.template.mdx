## Container Registry Hub (Docker)

Zenso publishes pre-built container images for self-hosters and homelab setups:

- **`ghcr.io/zensoink/zenso-api:latest`** *(🟡 WIP)*: Headless rendering service with Cairo & Chromium dependencies pre-installed.
- **`ghcr.io/zensoink/zenso-panel:latest`** *(🟡 WIP)*: Angular management web dashboard served over lightweight Nginx alpine image.
- **`postgres:16-alpine`** *(🟢 Official)*: PostgreSQL database engine storing configuration state and refresh schedules.
